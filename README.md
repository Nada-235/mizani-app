# ميزانيتي 💸

تطبيق ميزانية شهرية بالعربية مبني بـ Next.js وTypeScript وTailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Deployment

In Settings → Pages, select **GitHub Actions** as the source. Pushes to main deploy the static export.

## Privacy

Budget data is stored in browser localStorage, not in GitHub. Clearing website data can delete it.
